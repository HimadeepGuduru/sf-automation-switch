Is my password stored anywhere?
No. You log in directly on Salesforce — credentials never pass through this tool. The access token lives only in your browser.
What if I close the browser mid-migration?
Your snapshot survives in localStorage. A "pending revert" alert appears when you return with a one-click Reconnect button.
Do I need CORS and CSP in every org?
Yes — once per org. Use the Anonymous Apex script on the first tab. Settings don't transfer between sandboxes and production.
Workflow Rules show 0 — why?
WorkflowRule is unavailable in the Tooling API on some org editions (notably Vlocity/Industries). Salesforce platform limitation.
